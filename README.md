# 🍽️ Ne Pişirsek?

Annem her akşam "ne pişirsek?" diye sorar, babam da "bilmiyorum" der. Ben de yazdım. 👩‍💻

Ailem için geliştirdiğim kişiselleştirilmiş haftalık yemek planlama ve öneri uygulaması. Herkes kendi hesabından yemekleri puanlar, sistem ortak tercihlere göre haftalık menü oluşturur ve alışveriş listesi çıkarır.

## ✨ Özellikler

- 👨‍👩‍👧 Aile grubu oluşturma ve ortak menü planlama
- ⭐ Yemek puanlama ve kişisel tercih yönetimi
- 📅 Haftalık yemek planı (kahvaltı, öğle, akşam)
- 🛒 Otomatik alışveriş listesi
- 🔥 Kalori ve besin değeri takibi
- 💰 Haftalık bütçe tahmini

## 🛠️ Teknoloji Yığını

| Katman | Teknoloji |
|--------|-----------|
| Frontend | React + Vite |
| Backend | Python + FastAPI |
| Veritabanı | PostgreSQL (Neon) |
| Auth | JWT |
| Deploy | Vercel + Render |
