# 🍽️ Ne Pişirsek?

Kişiselleştirilmiş haftalık yemek planlama ve öneri web uygulaması.

## Özellikler
- Bireysel ve aile grubu yemek planlaması
- Kural tabanlı öneri motoru (ilerleyen aşamada ML)
- Kalori ve makro besin takibi
- Otomatik alışveriş listesi
- Harici tarif API entegrasyonu

## Teknoloji Yığını

| Katman | Teknoloji |
|--------|-----------|
| Frontend | React |
| Backend | Python + FastAPI |
| Veritabanı | PostgreSQL (Supabase) |
| Auth | Supabase Auth |
| ML | scikit-learn (ilerleyen aşama) |
